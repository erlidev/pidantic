# smart-compaction

Scaffold for a Pi extension that will customize conversation compaction. No behavior is
implemented yet.

The entry point registers no tools, commands, hooks, configuration fields, or environment
variables. It does not change Pi's compaction behavior and does not require any Docker service.

## Running standalone

Nothing to run. The entry point has no behavior to lose and no cross-extension links, standalone or
otherwise. When it grows an implementation, it gets a real section here.
